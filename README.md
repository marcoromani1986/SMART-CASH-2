# Smart Cash (Android)

Fast, offline personal cash management across multiple accounts and currencies built with Kotlin and Jetpack Compose.

## Features
- **Multi-Account & Multi-Currency**: Manage multiple cashboxes with independent balances in EUR (€), USD ($), and EGP (E£).
- **Dashboard & Currency Selector**: Instant total net worth calculation with currency tabs and recent activity stream.
- **Transfers with Exchange Rates**: Move funds between cashboxes with live exchange rate conversion.
- **Monthly Budgets**: Set spending limits per category and monitor real-time progress bars with safety indicators.
- **Recurring Transactions**: Automate periodic income and expense entries (daily, weekly, monthly) with automatic scheduling.
- **Ledger & Search**: Filter transactions by cashbox, category, or search keywords with newest/oldest sorting.
- **Reports & Analytics**: Breakdown by category and currency over today, this month, or custom date ranges.
- **Security & Privacy**: Optional 4-digit PIN app lock.
- **Data Portability**: Full JSON backup export/import and CSV spreadsheet export.
- **Multilingual & RTL**: English, Italian, and Arabic with native RTL layout support.
- **Offline & Private**: All data stored locally on device.
